# 经典后院设计系统 · v0.9

视觉方向保持选定的经典后院：纸张承载内容，木框承载导航和操作，叶绿表示植物和充能，阳光金表示经验、奖励及主要行动。禁止经验条使用魔法紫色。

## 唯一数据源

`src/design/tokens.json` 定义 22 个基础颜色和间距、字号、圆角、触控尺寸、动效及图层。`npm run design:tokens` 生成 CSS；`npm run check:design` 检查生成文件一致，并拒绝 UI 样式中的独立颜色字面量。Canvas 预警与地面特效直接读取同一 JSON。

| 语义 | 标记 | 用途 |
| --- | --- | --- |
| 正文 / 次级文字 | ink / ink-muted | 纸面文字，不能用浅金色正文 |
| 纸张 | paper / paper-shade / paper-deep | 内容卡、详情、禁用态 |
| 木框 | wood / wood-dark / wood-edge | 导航、边框、按钮与轨道 |
| 植物 | leaf / leaf-dark / leaf-light / leaf-pale | 充能、选中辅助状态、成功 |
| 阳光 | sun / sun-light | 经验条、主操作、金币 |
| 危险 | danger / danger-dark / danger-light | 敌方预警、Boss 生命、受击 |
| 钻石 / 冰冻 / 魔法 | gem / frost / magic | 专属资源或技能，不用于普通导航 |

## 尺度与规则

- 间距：0、4、8、12、16、20、24、32、40 px。常用卡片内边距 16–24，卡间 8–12，HUD 紧凑间隔 4–8。
- 字号：12 辅助说明、14 紧凑信息、16 正文、18 标签、24 标题、28–32 主视觉。数字使用等宽数字；不以颜色单独传递状态。
- 圆角：4 小标记、8 控件、12 卡片、999 进度条。图片尺寸、地图坐标和响应式布局宽度属于几何参数，不强行纳入间距刻度。
- 所有按钮最小高度 44 px；小屏优先滚动内容，保留固定主操作，横屏装备栏移至右侧。安全区使用 `env(safe-area-inset-*)`，不模拟手机边框。
- 快速反馈 120 ms、普通过渡 180 ms；减少动态模式关闭非必要 CSS 动画。
- 世界 / HUD / 弹层 / 通知 / 音乐 / 加载图层为 0 / 6 / 30 / 80 / 110 / 120。

## 组件约定与审核

| 组件 | 表达 |
| --- | --- |
| 经验条 | 深木轨道 + 阳光金填充 + Lv 数字 + progressbar 语义 |
| 生命与首领条 | 暖红体系 + 数字或名称；不用浏览器默认颜色 |
| 植物 CD | 深叶背景 + 浅叶充能 + 秒数 / 就绪 / 被动文案 |
| 主要行动 | 保留原金色按钮画稿，深色文字，44 px 以上触控高度 |
| 图鉴与商店 | 纸面信息卡、金色选中标签、深墨文字、明确禁用文案 |
| 加载 / 结算 | 同一轨道、颜色和字号；进度数字与实际资源解码绑定 |
| 模态与音乐 | 深叶遮罩、纸面内容、固定尺寸刻度；在线播放器本身为第三方内容 |

全部应用 UI 的颜色已迁入 token 引用，原始插画、第三方官方音乐播放器不重新染色。既有布局中的插画定位、响应式列宽仍保留项目特定尺寸。

## 战斗地面语言

敌方圆形预警的外沿等于伤害半径，倒计时扇形填满后命中；中心叹号、暖红描边和分段内环共同区分危险。冲锋使用带半圆端部的路径区域，覆盖冲锋距离及身体半径。钻地和施法保留独立目标标记。命中痕迹绘制在角色脚下，1.1 秒内消退。冰冻用冰蓝细环，磁力用紫色虚线，友方火焰用阳光金色火带，均与红色危险区区分。

`attack-geometry.ts` 同时供模拟和预警使用。阴影采用一次生成的透明贴图；高密度战斗只限制装饰性火苗、命中火花及伤害数字，不降低敌人数量、投射物或伤害结算。


## v0.9 战斗信息与声音

`tokens.combat` 定义友方效果透明度 0.68、危险边缘宽度 3、受击时间 0.3 秒、伤害标签预算 12。危险填充留在脚下，边缘在友方攻击上层重复绘制；敌弹保留实心与深描边，主角带浅色轮廓。脚底标记使用扁椭圆，不能画成使角色悬空的圆盘。

HUD 一至六个装备槽使用单行，超过六个才用双行；横屏使用原有侧栏。升级卡必须给出伤害或冷却的实际前后值，进化配方始终可查；满被动槽显示替换补救。最后防线用明确倒计时，避免无限延长战斗。

音乐分营地、普通、精英、首领四个状态，切换淡入淡出；暂停保存播放位置。危险音、战斗音与音乐分别调节。受击音继续使用最高优先级，危险提示还必须保留形状/方向/文字信息。原声外部播放器是单独的手动入口，不承诺随游戏自动暂停。
