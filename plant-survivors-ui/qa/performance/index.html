测试条件与限制

同一 Chromium 宿主，390 × 844，DPR 2，Canvas 780 × 1382；布局种子42，模拟种子20261117；预热30帧、目标180帧、18秒上限。每帧补齐实体并重置高生命，保证压力持续；包含24束激光和200条事件。normal：50怪/80弹/20敌弹/100掉落/6火区；ceiling：160/240/80/450/24；extreme：320/800/160/800/48，刻意超出正式上限。

工作耗时包含夹具维护、模拟与 Canvas 调用；夹具隔离了 React HUD 与音频，另外做受击音频和布局回归。rAF 间隔另列，包含浏览器合成与宿主调度，不能将脚本耗时换算成实际 FPS。CPU 4× 是降速模拟，不是某款实体手机。两轮仅用于本次前后比较，不能证明所有设备的稳定性。

基线极限 4× 两轮均未完成30帧预热；保留失败记录，不把缺失数据当作0ms，也不对这组宣称百分比。即使优化后完成采样，仍需真机验证长时间游玩、温度和GPU。
