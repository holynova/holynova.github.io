我们如何模拟速度

这里是交互演示，不调用模型 API，也不提供模型性能排名。所有内容、思考摘要和工具结果均为预置样例。编辑“示例问题”只修改界面中的问题，不会生成新的回答。语音场景仅展示字幕，不播放音频。

token ≠ 字符 ≠ 单词

不同模型的 tokenizer 不同。为保证可重复对比，本演示把每个中日韩文字、英文词块（最长 4 个字符）、标点或空白块作为一个模拟 token。数字均以此计算，不等同于真实 API token 用量。

等待与输出分开计算

首个回答 token 等待 = 首包延迟 + 思考/工具等待。回答输出耗时 = 回答 token 数 ÷ 设定 token/s。分块模式会等凑齐一批；卡顿模式会增加额外等待，因此实际平均速度会降低。暂停期间不计时。

“思考”展示什么？

示例摘要用于还原界面中的状态变化，不是真实模型内部推理，也不纳入回答 token 速度。四种终端为交互风格复刻，并非对应产品的实时界面或官方产品。
